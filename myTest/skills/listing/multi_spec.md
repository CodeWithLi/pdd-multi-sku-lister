# 多规格上架 Skill

## 素材目录结构

```
data/assets/商品上架规格文件/
└── {family_code}/              # 例如 BD046
    └── 第一套/
        └── {product_code}/     # 例如 BD046A
            ├── 1.png … 5.png   # 主图
            ├── 6.png           # 占位图，忽略
            ├── 7.png … 9.png   # 详情图
            └── {combo_code}.png # SKU 预览图，如 BD046A+AXBD001A.png
```

## 规则

- 每套图 = 一个独立上架商品
- SKU 中文名从 `sku+名称.xlsx` 检索，查不到则跳过并记录
- 货号格式：`{product_code}-{套图名}`（有套图时）

## 页面注意

- 发布页可能存在 A/B/C 三种 UI 分支，优先检测本地上传入口
- 规格分「款式」「型号」两维，需先录入规格名再填价格表
- 提交前确认所有预览图已上传
