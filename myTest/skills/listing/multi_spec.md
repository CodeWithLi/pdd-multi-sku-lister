# 多规格上架 Skill

## 素材目录结构

```
{product_code}/
├── 第一套图/
│   ├── 主图/1.png … 5.png
│   ├── 详情页/6.png … 8.png
│   └── {style_code}/
│       └── {style}+{model}/
│           └── 预览图.png
└── 第二套图/ …
```

## 规则

- 每套图 = 一个独立上架商品
- SKU 中文名从 `sku+名称.xlsx` 检索，查不到则跳过并记录
- 货号格式：`{product_code}-{套图名}`（有套图时）

## 页面注意

- 发布页可能存在 A/B/C 三种 UI 分支，优先检测本地上传入口
- 规格分「款式」「型号」两维，需先录入规格名再填价格表
- 提交前确认所有预览图已上传
